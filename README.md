# 見積書作成ツール (quote_builder)

他社の見積書 (Excel / CSV / PDF) を読み込み、明細と単価をもとに **自社の見積書 (Excel)** を作成します。

## セットアップ

```bash
pip install -r requirements.txt
cp company.example.json company.json   # 自社名・住所・担当者・登録番号などを編集
```

## 使い方

```bash
python -m quote_builder 他社見積.xlsx \
  -o 見積書.xlsx \
  --customer "〇〇工業株式会社" \
  --subject "事務所ネットワーク更新" \
  --rate 0.95 --round 10
```

| オプション | 内容 | 既定値 |
|---|---|---|
| `--rate` | 他社単価に掛ける率 (0.95 = 5% 安) | 0.95 |
| `--round` / `--round-mode` | 単価の丸め単位 (円) / `down`・`up`・`nearest` | 10 / down |
| `--tax` | 消費税率 | 0.10 |
| `--quote-no` / `--date` / `--valid-days` | 見積番号 / 発行日 / 有効期限日数 | 自動 / 本日 / 30 |
| `--company` | 自社情報 JSON | company.json |
| `--notes` | 備考 | company.json の `default_notes` |
| `--no-compare` | 「他社比較」シートを出力しない | |

サンプル: `python -m quote_builder samples/competitor_quote.xlsx`

## 出力される Excel

- **見積書** シート: 宛先・件名・納期・支払条件・有効期限・自社情報、明細 (No / 品名 / 仕様 / 数量 / 単位 / 単価 / 金額)、小計・消費税・合計。
  金額と合計は Excel の数式なので、出力後に単価や数量を直せば自動で再計算されます。A4 縦 1 ページ幅で印刷できます。
- **他社比較** シート: 品目ごとの他社単価・自社単価・差額・率 (社内用。提出時はシートを削除してください)。

## 読み込みの仕組み

- 「品名 / 品目 / 項目 / 内容 / 摘要」「数量」「単位」「単価」「金額」などの列見出しを自動で探します (全角・半角、空白の違いは無視)。
- `¥1,200`、`１５０，０００円`、`△500` のような表記も数値として読み取ります。
- 単価がなく金額だけの行は、金額 ÷ 数量で単価を求めます。
- 「小計」「消費税」「合計」などの行は明細から外します。
- 見出しの近くにある「株式会社〇〇」を比較元の会社名として拾います。
- PDF は表の罫線から読み取ります。罫線のない PDF やスキャン画像の PDF は読み取れないことがあるので、その場合は Excel か CSV に書き写してから読み込んでください。
