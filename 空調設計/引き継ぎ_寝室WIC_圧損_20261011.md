## 2. ダクトの構成（換気プラン図 V-upⅢ 2026/03/16 から判明）

- 空調機 DELIGHT（FY-BKS081）→ φ200 → **7分岐チャンバー FY-BBH081（φ100×7）**。
- 吹出口9箇所は「9等分」ではない。①→Y管E→納戸2箇所、②→玄関、ヌック、LDK、CL前、J→Y管J→脱衣とWIC（⑤）、④→主寝室。
- 1Fの③はトイレ排気φ50（給気ではない）。
- **DELIGHTの温度センサーが1F主寝室とWICの境目にある。**
- 計算書p25：SA風量はノッチ1〜7で270〜700㎥/h。p27：700㎥/h・200Paがシステム抵抗曲線の最大点。メーカーはφ200に700㎥/h（約6.2m/s）まで流す前提 → 講座の「4m/s未満」（第8回p58）とは基準が違う点に注意。
- 452.39㎥/h（冬朝O12）＝ φ200×4.00m/s。夏の参考値 437.7 ＝ φ200×3.87m/s（夏昼補助有）。

## 3. 圧損と配分（`ダクト圧損_風量配分.xlsx`）

- 第8回p56 の原単位（直管1.0Pa/m・曲がり1.5・分岐3.0・吹出3.0）で枝ごとのPaを出した。最長経路は④主寝室 約29Pa。
- 講座で習ったのは等速法（管径を決める方法）のみ。**Pa は「最長経路の圧損＜ファン静圧」の確認に使う**のが講座の筋。風量の割り振り（1/√Pa の比）は講座外の補足扱い。
- 配分の参考値（夏437.7）：簡易な7枝等分なら主寝室＋WIC 93.8㎥/h、圧損比なら 主寝室 約50＋WIC 約27 ＝ 約76㎥/h。玄関は 64〜68㎥/h で必要59.6を満たす → **以前の「予言② 玄関が不足」は9等分の仮定によるもので取り下げ**。
- ユーザー作成の圧損表は、Y管の共通行と脚を11行すべて合計して配っていた（二重計上）。7枝だけで合計するよう指摘済み。

## 4. 寝室・WIC の結論

- 必要風量 48㎥/h（吹出14.3℃）。等速法：φ100 で 1.70m/s＜4m/s ✓。
- 実際に来るのは約76㎥/h（28㎥/h 余り）→ 絞らないと室温 約23〜24℃（2〜3K 冷えすぎ、湿度は60%前後で問題なし）。温度センサーが主寝室前にあるため、全館の冷房が弱まり他室が暑くなるおそれ。
- 還気：主寝室扉 W780・アンダーカット15mm → αA＝117cm²×0.65＝76cm²（第2回p109・p111）。48㎥/h で 1.79m/s・1.9Pa ✓、76㎥/h で 2.78m/s・4.6Pa（気流音の境目）、94㎥/h で 3.4m/s ✗。
- 対策：WIC の吹出口を閉じる（主寝室1本で約50㎥/h）か、ダンパーで48㎥/h に絞る。
